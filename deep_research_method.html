小K超爱研究

怎么写出"可证伪"的深度研究：我们的一套系统

小K超爱研究 · 一份对外分享的方法论 适用：任何想写"有机制、可证伪、能累积"的深度文，而不是"丢个标题给AI生成的营销文"的人。

0. 先分清两件事：营销文 vs 深度研究

  • 营销文要的是「顺、抓人、转化」——值得做，但目标是传播，不是真。
  • 深度研究要的是「真、机制、可证伪」——目标是判断，不是流量。
  • 把深度研究当营销文写 = 资讯复读机 + 幻觉拼接。两套目标，两套工艺。
  • 一句话定义深度：深度 = 事实锚定 + 作用力推理 + 诚实B面。

1. 第一性原理：为什么"直接丢标题给AI"写不出深度文

AI 直接写，是从参数先验生成"最像真的那句话"，却没有你的真值库可钉、没有你的框架可推理、没有你的反方检查可克制。

幻觉根因不是"AI没数据"，是缺两层：① 验证过的 grounding 层（生成时把 claim 钉回真值库）；② 溯源 adjudication（权威源打架时，谁更可信的方法论）。

抖音 2026 营收不同渠道数不同、权威源也打架——这时候胜负不在"谁有数据"，在"谁有一套判定哪个数更可信的方法论"。你的库赢在每条数有 provenance（来源）+ 交叉核对。

2. 系统闭环（飞轮：越写越准）

  1. 数据库：事件库（带来源/情感）、估值库（真倍数）、价格真值库。
  2. 选题七维：热度 × 失衡 × 类型 × 流量 × 竞争 × 传播 × 拐点 × FinBERT。打分链中性，不偏任何标签。
  3. 作用力网络：L1 事件（表面不承重）/ L2 结构（承重=利益牵扯+互相作用力）/ L3 时间力（独立承重层）。五环分层 + 跨链桥把宏观↔产业串起来。
  4. SOP 六效合一：先写「判断核心句（X 从 A 变 B，因 C，意味着 D=利益方向）」；六式深挖（七寸 / 牌桌分离 / 三档情景 / 关键点力学）。
  5. 交叉验证总纲（三铁律）：数字回真值库 / 代码真跑 / 结构合规跑脚本。
  6. 双闸 + 门禁：要害判定（判断句落 L2）+ 机械分 + 零代码 / 无高危词 / 免责齐全。
  7. 落盘 + 回流校准：成稿进库，成为下一篇锚点。关键在回流——这是"一开始不准、越来越准"的机制。

3. 数据库三层（最小起步也要有）

  • 事件库：每条 = 日期 / 事件 / 类型 / 产业链 / 公司 / 影响方向 / 逻辑 / 影响级别 / 来源。事实与推演分开标。
  • 估值库：真 PB / PS / PEG（别用编造或陈旧数；缺失就显式标"待补"）。
  • 真值库：价格等可核验快照，作为交叉验证锚点。
  • 铁律：每条数带来源；不同源冲突时记下来，不偷偷选一个。

4. 选题：七维打分（去偏版）

  • 公式：选题总分 = (热度 + 失衡) × 类型 × 流量 × 竞争 × 传播 × 拐点加成 × FinBERT 乘子[0.85–1.20]。
  • 关键：打分链中性，不得因"属于某类"就加权；FinBERT 只做情感微调，不放大任何标签。
  • "掺着写"：1 篇骑热度（final_score 最高）+ 2 篇走在前（拐点驱动 + 新链空白 + 命中串联，强制异链）。

5. 作用力网络（深度文的灵魂）

  • 永远先问："这事变了，整件事会不会跟着变？" 会变 = 承重关键点（L2）。
  • 写出「谁对谁施加什么方向的力」（增强/削弱）；正反馈回路最高价值（会碾压不在回路里的结构）。
  • 最容易出彩 = 把表面无关的两件事，用利益牵扯连起来，找出互相作用力（例：AI 自研潮→HBM 需求→韩供应商；韩国加息是这景气的货币回声，不是独立利空）。
  • 反方检查（AI 做不到的克制）：显式列「若错，最可能错在哪」2–3 条，别双重计分。
  • D 值强度打分（-5 ~ +5）：每条力除了方向，再标一个强度 D ∈ [-5, +5]（正向增强 +1~+5 / 负向削弱 -1~-5 / 中性 0）。让力网从「有方向」升级为「有量级」——可排序、可对比、可识别「哪条力才是真承重」。例：NVDA→硬件链需求外溢 D≈+4；加息→韩元折算逆风 D≈-1（弱）。没有 D 值的力网是草图，有 D 值的力网才是可计算的机制。
  • 时间力独立承重层（L3，短/中/长）：时间不再是「按需备注」，而是独立承重维度。每条力标注时效：短（<3月）/ 中（3–12月）/ 长（>1年）。例：NVDA 季报是短力、HBM 长协锁量是中力、太空算力是长力（2027+ 期权）。带时间力后，三档情景的「切换触发器」才有时间坐标（短力先触发、长力定方向）。

6. 写作 SOP 六效合一（浓缩）

  • 道：先想清楚再动笔。"想不清楚，这篇就不写。"
  • 判断核心句：出稿前强制写「X 从 A 变 B，因 C，意味着 D」。写不出 D（利益方向）= 没找到关键点。
  • 六式组合（防过拟合）：技术机制稿 七寸+技术细节；产业格局稿 牌桌分离+格局；规模稿 三档情景；所有深度稿 默认写判断核心句。
  • 牌桌分离：比较多方时拆成不同牌桌（专利桌 vs 出货桌 vs 定价桌），防二元粗暴结论。
  • 三档情景：规模/宏观给 Bull/Base/Bear 区间，幅度不编造——精确弹性待回测，不给未经验证的"XX%"。

7. 交叉验证总纲（三铁律，P0）

  • 数字回真值库：带数字必注出处，核心结论附证据等级。
  • 代码真跑：涉及计算的逻辑用脚本实跑，不心算。
  • 结构合规跑脚本：用检查器机械过门禁。
  • 可证伪进引擎：每条预测/判断必须带 Falsification_Score——明确「什么证据出现 = 我错了」，并自动喂进「预测登记表」真账本（标的/方向/基准日/持有期/比较基准/核心逻辑）。期末由价格真值库自动核验命中，形成「判断 → 登记 → 验证 → 回流校准」闭环。这正是一套系统命中率可信的根：不是写完就忘，是每条都进账本等打脸。
  • P0 缺口：时间序列仓库（OHLCV 历史）——补完即能量化"韩元升值拖累多少折算盈利"这类问题（长协占比作分母时直接可算）。

8. 取长补短：外部泛化脑 + 内部校准层（双层架构）

  • 外部脑（通用大模型，含网页版 DeepSeek）：没你的库 → 泛化强、套壳流利 → 角色=结构/类比/框架生成器。价值是流利，不是真理。
  • 内部层（你的数据库+SOP+门禁+交叉验证）：角色=事实/验证/克制。把外部脑给的骨架钉回真值：填真数、扔编造、补反方检查、过双闸。
  • 分工铁律：外部脑出结构，内部层校准事实。 典型样本——外部脑给 Bull/Base/Bear 骨架（泛化好），但 EPS 弹性"XX%"、出口"20%拐点"是编的（精度崩）；内部层填真数、扔编造（精准）。

一句话：直接写赌 AI 记性，数据库写赌你的校准。 AI 记性会漂，你的校准越积越实。

10. 落盘与回流（收口纪律）

  • 成稿一律进统一目录收口，便于数据库整理与检索（不要东一篇西一篇）。
  • 成稿的事实/判断/证伪结果回流进事件库/估值库，成为下一篇锚点。
  • 宏观×产业题材强制三占位符：【资产映射】【国内映射·严禁代码】【证伪条件】，否则不出终稿。

11. 给想写深度研究的人：最小可行起步

  1. 建一个带来源的事件本（哪怕 Excel）。
  2. 每篇先写「判断核心句（D=谁受益/受损）」，写不出就别写。
  3. 强制列反方检查（若错最可能错在哪）。
  4. 让外部模型出结构，你钉事实（填真数、扔编造）。
  5. 成稿回库，飞轮转起来。
不靠大模型，靠这一套循环。

12. 我们还在做的（工程化方向）

把上述方法论进一步沉淀为可复用的工程能力：写作路由输出结构化字段（核心机制 / 必用工具 / 红线禁项 / 三占位符 / D值强度 / 时间力 / Falsification_Score），让出稿 Agent 从「读散文」升级为「读结构化 recipe」；并对「提前给出、且到期验证成立」的预判加权，鼓励长视野而非追热点。这部分仍在排期，先以人工跑通方法论为优先。

合规红线（对外）：零A股代码；无高危词（牛市/红利是真的/不是炒出来的/接盘式崛起）；落产业机制非标的；带免责声明。内部研究可带低估/高估视角，但数据诚信底线（不编造、标来源、假设透明）始终守。
