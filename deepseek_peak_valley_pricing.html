DeepSeek一年只赚5亿美元，却投了470亿建机房

📅 2026 年 08 月 20 日⏱ 阅读约 5 分钟🏷 AI 产业链 · 深度拆解
DeepSeek一年只赚5亿美元，却投了470亿建机房

深度拆解

> 判断核心句：把 DeepSeek 的账算到底：年收入约 5 亿美元，1GW 算力中心要投 470 亿美元，一年电费 13 亿美元——按现在的赚钱速度，这套机房 94 年都回不了本。但 DeepSeek 根本不打算靠 API 回本：它用 148 倍市销率融资到 710 亿美元估值，赌的是"收入爆炸"这个未来故事。峰谷涨价 1100% 不是贪婪，是杯水车薪的挣扎。

开场：别人算它赚多少，我把收支一起算到底

全网都在算 DeepSeek 涨价：高峰涨 1100%、闲时五折、每百万 Token 多少钱。

我不复述价格表。我想干一件没人干过的事：把 DeepSeek 的收支账算到底——收进来多少、付出去多少、亏还是赚、多久回本。

先给结论，再算给你看：

  • 收入：年化营收约 4-5 亿美元（约 36 亿人民币），主要靠企业 API 调用；
  • 成本：1GW 算力中心要投 470 亿美元（约 3,384 亿人民币），一年电费 13 亿美元；
  • 回本：按现在的赚钱速度，这套机房 94 年都回不了本；
  • 真相：DeepSeek 不靠 API 回本，它靠 148 倍市销率融资——峰谷涨价只是把年收入从 5 亿推到 8 亿的小动作，杯水车薪。

第一笔账：收入——一年收多少？

先看收入端。

DeepSeek 不是上市公司，财报数字不公开。但 2026 年 8 月，36 氪引述市场口径给出了一个数：

> DeepSeek 年化营收（ARR）约 4-5 亿美元，主要来自企业 API 调用服务，约合 29-36 亿人民币。

这个数可信吗？交叉验证一下：事件库里有一条——DeepSeek V4 Flash 单日消耗 8 万亿 Token，登顶全球调用量第一。8 万亿/天的量级确实是全球第一（比 OpenAI 的旗舰还高），但"调用量第一"不等于"收入第一"——DeepSeek 的 App 免费、大量调用走缓存命中（0.1 元/百万，几乎白送）、国产替代定价更低。所以"量全球第一、收入只有 5 亿美元"是合理的：它把白菜价的量做成了全球第一，但没赚到多少钱。

再对比：估值 710 亿美元 ÷ 年收入 5 亿美元 = 市销率 148 倍。作为参照，OpenAI 上市前估值触万亿美元时 P/S 约 30-40 倍，成熟科技公司 10 倍以内。148 倍意味着：市场在为 DeepSeek 的未来 10 倍收入增长付钱。

第二笔账：支出——1GW 机房要花多少？

收入算完，算支出。这部分的数字都有明确出处：

设备（30 万张 B200，彭博社 8 月 1 日报道 DeepSeek 计划在乌兰察布建 1GW 数据中心）：

  • B200 售价约 4 万美元/颗（专业拆解机构 Silicon Analysts，2026-03），制造成本仅 6,750 美元（HBM3E 内存占 48%），英伟达毛利率约 83%；
  • 30 万张 × 4 万美元 = 120 亿美元 ≈ 864 亿人民币——这是裸 GPU 价。

总投入（1GW 全套，英伟达代工伙伴鸿海董事长刘扬伟口径）：

> 每 1GW 英伟达 Vera Rubin 数据中心，资本开支高达 470 亿美元（GPU + 土建 + 供配电 + 散热 + 网络），每年电力成本约 13 亿美元。

470 亿美元 ≈ 3,384 亿人民币。而 DeepSeek 首轮外部融资募资约 70-74 亿美元（约 510 亿人民币）——只够 1GW 的 15%。

电费（运营大头）：

  • 1GW 年耗电约 52.6 亿度（按 60% 负载率粗算）；
  • 乌兰察布园区直供电价 2 毛出头/度 → 年电费约 10.5 亿元；东部一线 0.7 元/度 → 36.8 亿元；
  • 选乌兰察布，一年省约 26 亿元（业内口径：电费比东部沿海低 30%-40%）。

第三笔账：亏还是赚？多久回本？

现在把收支摆到一张桌上。

情景一：现状（1GW 未满负荷）

  • 年收入：约 5 亿美元（36 亿人民币）；
  • 年运营成本：电费（若已有数百 MW 规模，按 1/3 计）约 3-4 亿美元 + 人力、带宽、维护 ≈ 合计 5-6 亿美元；
  • 结论：收入勉强覆盖运营成本，勉强打平或微亏——这就是它还能撑下去的原因：光运营不亏太多，但资本开支（470 亿）根本没赚回来。

情景二：1GW 全部建成、满载运行

  • 年收入：仍是约 5 亿美元（收入不会因为建完机房自动涨）；
  • 年成本：电费 13 亿美元 + 折旧（470 亿按 5 年摊）94 亿美元 + 人力 ≈ 每年 110 亿美元；
  • 结论：收入 5 亿 vs 成本 110 亿，每年巨亏 105 亿美元。

回本测算：

  • 静态回本：470 亿美元 ÷ 年收入 5 亿美元 = 94 年；
  • 乐观假设收入每年翻倍（5→10→20→40→80 亿美元），也要 5-6 年收入才勉强覆盖年成本（电费+折旧），届时累计投入早已超过 500 亿美元——依然没有真正回本；
  • 唯一的"回本"路径：IPO。DeepSeek 已启动上市准备（传 2027 年科创板），二轮融资投前估值已到 710 亿美元——投资人赚不赚、DeepSeek 活不活，靠的是二级市场接盘，不是 API 收入。

收尾：算到底，你才看懂它为什么涨价

三张表算完，DeepSeek 的真相浮出水面：

它是一家收入撑不起资本开支的公司，在拿 148 倍市销率赌未来。

  • 年收入 5 亿美元 vs 1GW 投入 470 亿美元——94 倍的鸿沟；
  • 峰谷涨价 1100%：就算把 ARR 从 5 亿推到 8 亿，离 110 亿美元的年成本依然差着一个数量级——杯水车薪；
  • 但涨价对"故事"有用：收入涨 60%，P/S 从 148 倍降到 90 倍，估值故事更"讲得动"——这才是涨价真正的目的；
  • 电费 2 毛（乌兰察布）、算法省电（MoE）、利用率抠到极致（峰谷定价）——这些不是情怀，是在收入撑不起成本的世界里，把每一分可控制的成本压到最低，把账本做得尽可能好看，好让融资和 IPO 的故事继续讲下去。

大模型 API 开始像电费一样按峰谷定价，这件事本身值得记住：当一家公司开始精细定价，说明它已经从"烧钱换规模"进入了"算账求生存"——而 DeepSeek 的账本，是 5 亿美元的收入撑着一套 470 亿美元的机房。

这个落差，就是 AI 行业 2026 年最真实的样子。

Q&A

Q1：DeepSeek 一年真的只赚 5 亿美元？

这是 36 氪 2026-08 引述的市场口径（年化营收 ARR 4-5 亿美元，主要来自企业 API）。DeepSeek 未上市不披露财报，但交叉验证合理：V4 Flash 单日消耗 8 万亿 Token 全球第一，但 App 免费、大量缓存命中低单价，量价倒挂——量全球第一，收入只有 5 亿美元。

Q2：470 亿美元 1GW 数据中心靠谱吗？

这是英伟达代工伙伴鸿海董事长刘扬伟 2026 年的公开口径（Vera Rubin 全配置：GPU+网络+土建+供配电+散热）。DeepSeek 的乌兰察布 1GW 是彭博社 8 月 1 日报道的计划。实际金额取决于配置与议价，但量级没错：万卡集群是百亿美元级生意，1GW 是千亿人民币级项目。

Q3：94 年回本是认真的吗？

是静态测算：470 亿美元投资 ÷ 5 亿美元年收入。它的含义不是"DeepSeek 会亏 94 年"，而是"以现在的赚钱速度，靠 API 永远回不了本"。DeepSeek 的算盘不在 API——在融资（二轮投前估值 710 亿美元）和 IPO（传 2027 年科创板）。

Q4：那 DeepSeek 会不会倒闭？

大概率不会，因为它有两条命：一条是 148 倍市销率撑起来的融资能力（710 亿美元估值），一条是国字头股东（国家 AI 产业投资基金、腾讯、宁德时代）和"国产开源标杆"的政策地位。但"不倒闭"和"靠 API 赚钱"是两回事——它靠的是资本市场的钱，不是 API 的钱。

Q5：普通开发者怎么办？错峰调用真的省一半吗？

真的。闲时五折是实打实的折扣：批量处理、代码生成、模型评测这类不赶时间的任务挪到晚上，成本直接砍半。对开发者这是省钱技巧；对 DeepSeek 这是把 17 小时空转的 GPU 卖出第二遍——同一件事，两边都划算。
