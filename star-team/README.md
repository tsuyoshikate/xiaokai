# 星际小队 · 16 款游戏试玩版

第一批 8 款完整网页小游戏：数字轨道、星球信号、太空配对、飞船通行灯、星际分拣站、陨石找目标、航线记忆、机器人指令。

第二批 8 款：反向导航、星际货运清单、卫星追踪、星球搬家、太空拼图、星系补规律、等信号再出发、小小任务链。大厅按主要练习目的分为四个文件夹，每个恰好四款游戏；文件夹封面显示全部游戏名称与不同的原创图标。

在线试玩：[打开星际小队](https://tsuyoshikate.github.io/xiaokai/star-team/)，可以直接分享这个链接。

## 开始试玩

在此目录运行 `npm run dev`，打开 http://127.0.0.1:5188 。无需安装依赖。也可以运行 `node server.mjs`。

先选择「今日星际旅程」或「太空休息站」→ 邀请小猫或小狗。选择星际旅程后才展示四个游戏文件夹；选择休息站后只展示四种休息方式。游戏路线：选择文件夹 → 家长选择任务 → 调整难度和动态 → 试玩或正式回合 → 完成。数字轨道可选 10、20、30、50 个数字。

初始页面只展示两个活动入口，伙伴选择单独一页。进入后可重新选择活动；刷新页面会回到初始选择，已有积分、礼物、装扮和保存的旅程进度继续保留。游戏文件夹上方可安排或继续一段练习与休息。

同一台电脑可直接使用本地地址。当前服务器仅监听本机，不向外网发布；手机实机访问需要另行配置网络访问。

## 设计说明

### 用家长能理解的场景说明用途

首页用「前额叶训练」概括游戏入口，以提升专注力、记忆力、自控力与规划力作为练习目标；休息入口突出「休息，是为了走更长远的路」。封面只保留简短功能说明；这些是练习方向，不是针对本产品验证过的改善效果。四个分类名称位于各自文件夹上方，保留「四个文件夹，四种探索方向」总标题，去掉分类封面的小字。具体场景与练习动作在后续页面说明。

伙伴页说明这一步是自主选择陪伴；16 款游戏在选择、准备与进行页写清具体练习动作，完成页回顾实际做过的动作。休息详情、旅程各步骤、宠物兑换与家长记录也说明当前页面的用途。

目的文案集中在 `purpose.js`，新增游戏应同时补充练习动作、家长场景与可观察的过程。游戏表现不作为能力评估，也不承诺日常表现改善或治疗效果。

参考资料：[哈佛儿童发展中心的游戏与执行功能活动](https://developingchild.harvard.edu/resources/handouts-tools/brainbuildingthroughplay/)说明注意、工作记忆、自我控制可以成为游戏练习的方向；[NCCIH 放松方法说明](https://www.nccih.nih.gov/health/relaxation-techniques-what-you-need-to-know)介绍呼吸、身体放松等方法。两者为一般设计参考，不是本产品有效性的验证或机构背书。

- 适合 6–9 岁儿童与家长一起试玩，是游戏练习工具，不提供诊断、治疗保证或临床评估。
- 动态速度独立于任务难度，可静止、慢速、标准。系统减少动态偏好下默认静止。
- 小屏幕放不下 30/50 个数字时使用静止完整布局，可滚动，不减少数字数量。
- 页面隐藏自动暂停，返回后手动继续。暂停冻结游戏阶段、轨道和有效游戏时间。
- 每款游戏的设置与最近 20 次完成的正式回合保存在本机 localStorage，可在页脚「家长 · 最近的探索记录」查看或清空；带练不记入，不收集儿童身份数据，也不上传游戏记录。
- 两批代码、SVG 图形和游戏规则实现为原创，没有复制候选 GitHub 项目源码或素材。图标使用系统 Emoji。
- 星球信号和航线记忆完成三组序列；通行灯和分拣站各十次；找目标六次；配对和机器人各一轮。试玩使用短回合。
- 第二批：反向导航八题；货运清单和卫星追踪各三轮；星球搬家和拼图各一局；规律六题；等信号五轮或七轮；任务链两轮。所有游戏都有缩短的试玩模式。
- 卫星追踪在减少动态模式中使用短距离分步移动，保留跟随目标的任务；其他不必要运动停用。
- 星球搬家提供合法移动提示与撤销；拼图通过合法移动洗牌保证可解，使用 A* 给出下一步提示，支持撤销。

## 检查

`npm run check` 检查语法，`npm test` 检查数字完整性、序列比较、机器人合法移动、暂停时钟、星球搬家及拼图可解性。

浏览器验收脚本：`node qa/browser.mjs`。它需要通过 `PLAYWRIGHT_MODULE` 提供已安装 Playwright 的模块文件路径，不属于应用运行依赖。

额外交互验收：`node qa/interactions.mjs`。若已安装浏览器的版本与 Playwright 默认版本不同，可通过 `PLAYWRIGHT_BROWSER` 指定已有浏览器可执行文件。验收记录见 `qa/VERIFICATION.md`。

第二批完整回合与布局验收：`node qa/batch2.mjs`，使用相同的 Playwright 环境变量。验收报告见 `qa/batch2-report.json`。

当前范围包含两批共 16 款游戏。没有 AI 调用、账号或后台；已通过 GitHub Pages 发布。

## 2026-10-10 体验升级

- 机器人指令：12 张不同地图，每关均用搜索验证可达且可在 20 条指令内完成；完成可进入下一关，三级提示逐渐展开。
- 星系补规律：AB、AAB、ABB、ABC 重复组合，随机起点与增量，进阶可出现递减数量；三级提示从观察规则到答案。
- 小小任务链：3 类物品、3 个目的地随机匹配，可选 1–3 组（2/4/6 步），收货点明确显示对应物品；重看保留已完成步骤和手中物品。
- 卫星追踪：4/6/8 颗卫星独立移动和避让，可选 1/2/3 个目标；暂停冻结位置，减少动态时短距离分步移动。
- 信号和航线可选起始记忆数量、每个信号播放时间；货运可选起始数量。观察清单/目标默认等孩子确认，也可选择 6/10/15 秒。
- 带练模式提供随当前步骤变化的提示；反向导航支持方向键，Escape 暂停/恢复；重绘时尽量保留操作焦点。
- 完成反馈根据玩法变化；每款游戏的自定义设置分别保存。

升级验收：node qa/upgrades.mjs（同样需要设置 Playwright 环境变量）。这是桌面 Chromium 与模拟手机/平板尺寸的自动检查；iPad Safari、Android 手机实机尚未验收。

## 练习与休息交替（v1.2）

大厅增加「今日星际旅程」和「太空休息站」。旅程先问状态，再选择两项不同任务组的短回合，第一项后进入放松与离屏活动，第二项自愿选择。孩子可以只休息或提前结束，没有连续签到、排名或休息得分。

- 旅程回合复用原有带练的短回合规则；机器人可在准备页选择关卡。数字轨道为 1–5，其他任务也缩短回合数，不要求玩满规定时间。
- 家长可选择约 2/3/4 分钟后提醒休息；计时到达只显示提示，不中断任务。重试较多时提示寻求帮助或休息，不推断孩子的情绪。
- 未完成游戏在休息、回大厅、刷新时保留进度，包括位置、指令和当前阶段。也可选择「保存，下次再玩」；选择结束感受并完成降落会关闭本次旅程。恢复时先暂停，手动继续。进度存于当前浏览器，清除浏览器数据会丢失，不能跨设备恢复。
- 休息站提供轻柔呼吸、身体放松、安静故事、离屏活动。呼吸支持两种参考节奏及自己呼吸，系统减少动态偏好下光圈静止。页面隐藏暂停引导，回来后手动继续。
- 故事朗读依赖设备的语音合成功能与中文语音，不保证所有设备可用；始终保留文字及家长朗读方式。朗读在离开或暂停时停止。
- 离屏活动不要求盯着计时。锁屏、切换页面的时间不计入；选择次数与前台计时不能验证实际活动时长。
- 已结束旅程的任务、放松选择、离屏环节及前后主观感受只保留最近 20 次，可单独清空。旅程短回合不会重复计入正式游戏记录。

初始时间是产品试玩安排，不是医学训练剂量。本项目尚未验证促进前额叶发育、治疗发育迟缓或改善日常执行功能的效果。孩子不舒服时停止；有确诊发育问题时，结合专业人员建议安排。

设计参考：[哈佛儿童发展中心的执行功能活动指南](https://developingchild.harvard.edu/resources/handouts-tools/activities-guide-enhancing-and-practicing-executive-function-skills/)、[NIH 儿童身心练习资料](https://www.nccih.nih.gov/health/tips/things-to-know-about-mind-and-body-practices-for-children-and-teens)、[美国儿科学会的媒体使用建议](https://www.healthychildren.org/English/family-life/Media/Pages/Tips-for-Parents-Digital-Age.aspx)。参考资料不代表对本项目的认可或效果验证。

新流程验收：`node qa/journey.mjs`；16 款游戏休息与刷新恢复验收：`node qa/journey-games.mjs`。使用前述 Playwright 环境变量；脚本保存在开发工作区。

## 积分、宠物与礼物（v1.3）

可以选择小猫或小狗，完成任何小游戏后收集星星积分，再兑换虚拟礼物送给伙伴。猫狗共用礼物口袋，各自保留帽子、领结和点心；随时可以换伙伴。伙伴没有饥饿、情绪下降或喂养倒计时，休息和离开不会受到惩罚。

当前奖励任务数为 15 个普通游戏 + 12 个机器人关卡 = 27。每个任务首次完成短回合奖励 5 分；完成完整回合累计到 10 分（已获得 5 分时补发 5 分）。同一任务重玩不重复加分，难度、速度、用时、帮助与重试不影响奖励。旅程中的短回合也可获得 5 分；休息不计分，提前结束不扣分。过去版本的游戏记录保留，积分从本版本启用后完成的回合开始计算。

累计可获得最多 **270 分**，可用余额为累计积分减去已兑换礼物的价格；没有每日清零、过期、连续签到、排行榜或限时促销。

| --- | ---: |

| 薄荷领结 | 15 |
| 星星小帽 | 20 |

每件只兑换一次，永久拥有。兑换前确认花费，余额不足时不能购买；送给伙伴不再扣分。点心作为可反复使用的虚拟互动礼物，不设置消耗后的补购。装备可以收好、再戴上，也能给猫狗分别使用。游戏与休息进行中不打开礼物商店，旅程结束后可前往送礼。

积分与宠物保存在 `star-team-pets` 的当前浏览器存储中，不跨设备同步。清除浏览器数据后会丢失；这是无账号的本地 demo，不提供服务端反作弊或多设备钱包，也不能兑换实物。

后续扩展：奖励预算根据游戏清单和机器人关卡配置计算，新增游戏自动增加 10 分预算；增加机器人关卡时同步调整关卡列表。礼物采用独立目录，当前物品价格与已拥有礼物保持稳定。新增小屋、猫爬架、食碗、水碗、猫窝、逗猫棒时，可增加房间装备位置与礼物条目，并核对新增任务的积分是否足够兑换新增物品。该版本尚未实现小屋家具。

积分纯逻辑测试见 `tests/pets.test.mjs`；浏览器验收见开发工作区 `qa/pets.mjs`，包含短/完整回合、重复奖励、兑换确认、余额、猫狗切换、装备、刷新与手机尺寸。
